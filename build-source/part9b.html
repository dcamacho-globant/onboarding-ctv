After login: session and token

  1. Se guardan los datos. El perfil queda en gigyaDataState y el token en nflTokenState, ambos persistentes ({{C:src/atoms/userState.ts:26}}, {{C:src/atoms/userState.ts:21}}). UserManager.setUserData ({{C:src/managers/UserManager/UserManager.ts:165}}) los escribe y vuelve a registrar el token.
  2. ¿Hay sesión? isSignedIn ({{C:src/managers/UserManager/UserManager.ts:123}}) es cierto si hay un UID y no hay código de error.
  3. Un solo lugar entrega el token. registerToken ({{C:src/managers/UserManager/UserManager.ts:352}}) deja a NFLAPIConfig una función getAuthToken ({{C:src/managers/UserManager/UserManager.ts:363}}). Si el token está vencido o hay un refresco forzado, pide uno nuevo ({{C:src/managers/UserManager/UserManager.ts:514}}, definido en {{P:apps/shared/src/utils/getRefreshableNFLToken.ts:442}}); si no, entrega el guardado. Por eso toda llamada a la API ({{C:src/nflApi/Experience.ts:77}}) lleva un token vigente.
  4. Cerrar sesión. clearLoginCredentials ({{C:src/managers/UserManager/UserManager.ts:384}}) borra los datos de cada proveedor, y clearGigya ({{C:src/managers/UserManager/UserManager.ts:251}}) vacía el perfil, el token y los datos de OIDC, y registra un token nuevo.
  1. The data is stored. The profile goes in gigyaDataState and the token in nflTokenState, both persistent ({{C:src/atoms/userState.ts:26}}, {{C:src/atoms/userState.ts:21}}). UserManager.setUserData ({{C:src/managers/UserManager/UserManager.ts:165}}) writes them and registers the token again.
  2. Is there a session? isSignedIn ({{C:src/managers/UserManager/UserManager.ts:123}}) is true when there is a UID and no error code.
  3. One place hands out the token. registerToken ({{C:src/managers/UserManager/UserManager.ts:352}}) gives NFLAPIConfig a getAuthToken function ({{C:src/managers/UserManager/UserManager.ts:363}}). If the token is expired or a refresh is forced, it requests a new one ({{C:src/managers/UserManager/UserManager.ts:514}}, defined in {{P:apps/shared/src/utils/getRefreshableNFLToken.ts:442}}); otherwise it returns the stored one. That is why every API call ({{C:src/nflApi/Experience.ts:77}}) carries a valid token.
  4. Signing out. clearLoginCredentials ({{C:src/managers/UserManager/UserManager.ts:384}}) clears each provider's data, and clearGigya ({{C:src/managers/UserManager/UserManager.ts:251}}) empties the profile, the token and the OIDC data, and registers a fresh token.
