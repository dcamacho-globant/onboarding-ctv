Las 5 piezas clave

The 5 key pieces

1. La App raíz (una para web, otra para nativo). {{C:src/App.web.tsx:80}} y {{C:src/App.tsx:168}}. Arman los "envoltorios" (estado, React Query, navegación, Sentry) donde vive todo lo demás. En web, el parámetro ?device= decide para qué TV se ejecuta ({{C:src/App.web.tsx:125}}).
1. The root App (one for web, one for native). {{C:src/App.web.tsx:80}} and {{C:src/App.tsx:168}}. They build the "wrappers" (state, React Query, navigation, Sentry) that hold everything else. On web, the ?device= query parameter decides which TV it runs for ({{C:src/App.web.tsx:125}}).
2. Servicios y feature flags. {{C:src/App.tsx:185}} y {{C:src/App.tsx:193}}. Al arrancar se enciende FeatureService (Flagsmith): prende o apaga funciones sin publicar una versión nueva. Hay valores de respaldo si no hay red (src/constants/flagsmithFallbacks/).
2. Services and feature flags. {{C:src/App.tsx:185}} and {{C:src/App.tsx:193}}. On startup FeatureService (Flagsmith) is turned on: it enables or disables features without shipping a new release. There are fallback values for when there is no network (src/constants/flagsmithFallbacks/).
3. Los navegadores. {{C:src/navigators/RootStackNavigator.tsx:91}} y {{C:src/navigators/SideBarNavigator.tsx:93}}. Deciden qué pantalla se ve; el menú lateral es el principal. Las pantallas se cargan solo cuando se necesitan (React.lazy).
3. The navigators. {{C:src/navigators/RootStackNavigator.tsx:91}} and {{C:src/navigators/SideBarNavigator.tsx:93}}. They decide which screen you see; the side menu is the main one. Screens are loaded only when needed (React.lazy).
4. La capa de datos. {{C:src/hooks/api/useFetchExperience.ts:61}} → {{C:src/nflApi/Experience.ts:32}} → {{P:nfl-api/src/axiosInstance.ts:159}}. Los hooks piden datos, la API agrega el token y el cliente HTTP reintenta una vez si el servidor responde 401.
4. The data layer. {{C:src/hooks/api/useFetchExperience.ts:61}} → {{C:src/nflApi/Experience.ts:32}} → {{P:nfl-api/src/axiosInstance.ts:159}}. Hooks ask for data, the API adds the token, and the HTTP client retries once if the server answers 401.
5. El reproductor de video. {{C:src/components/CTVVideo/CTVVideo.tsx:91}}. Envuelve el reproductor de @nfl/video (basado en THEOplayer, {{C:src/components/CTVVideo/CTVVideo.tsx:543}}) y le suma analítica y reglas de acceso ({{C:src/utils/video.ts:94}}).
5. The video player. {{C:src/components/CTVVideo/CTVVideo.tsx:91}}. It wraps the @nfl/video player (based on THEOplayer, {{C:src/components/CTVVideo/CTVVideo.tsx:543}}) and adds analytics and access rules ({{C:src/utils/video.ts:94}}).
