Cómo viaja un evento

How an event travels

  1. La app arma las propiedades. Una pantalla o un clic llama a Analytics.shared.trackView o trackAction con propiedades como el ID de la app, la versión, la suscripción y el estado de los anuncios ({{C:src/utils/analytics.ts:368}}). Es el mismo código en las dos plataformas.
  2. Nativo: vista de página. Analytics.native llama a AdobeExperiencePlatform.trackView ({{P:apps/shared/src/containers/Analytics.native.ts:412}}). Ese método no envía nada si el usuario no dio consentimiento o Adobe no está disponible ({{P:apps/shared/src/containers/AdobeExperiencePlatform.ts:113}}) y, si todo está bien, usa MobileCore.trackState ({{P:apps/shared/src/containers/AdobeExperiencePlatform.ts:107}}).
  3. Nativo: acción (clic). Pasa por trackEvent ({{P:apps/shared/src/containers/Analytics.native.ts:510}}, {{P:apps/shared/src/containers/AdobeExperiencePlatform.ts:120}}), que usa MobileCore.trackAction. En TV, si el flag de Edge está activo, ambas se envían en cambio como un evento de Edge con tipo analytics.track ({{P:apps/shared/src/containers/AdobeExperiencePlatform.ts:83}}, {{P:apps/shared/src/containers/AdobeExperiencePlatform.ts:92}}).
  4. Web: vista de página. Analytics.web junta los datos y llama a _satellite.track("virtual_pv", datos) ({{P:apps/shared/src/containers/Analytics.web.ts:413}}). Las acciones usan _satellite.track con el nombre de la acción ({{P:apps/shared/src/containers/Analytics.web.ts:479}}). En web, AdobeExperiencePlatform.trackView está vacío ({{P:apps/shared/src/containers/AdobeExperiencePlatform.web.ts:10}}): lo hace Analytics.web directamente.
  5. Una advertencia del código. Los comentarios del código dicen que una propiedad nueva no aparece en Adobe hasta que el equipo de Analytics la asigne a una variable en Adobe Launch, aunque llegue a _satellite.track.
  1. The app builds the properties. A screen or a click calls Analytics.shared.trackView or trackAction with properties such as the app ID, version, subscription and ad-block state ({{C:src/utils/analytics.ts:368}}). It is the same code on both platforms.
  2. Native: page view. Analytics.native calls AdobeExperiencePlatform.trackView ({{P:apps/shared/src/containers/Analytics.native.ts:412}}). That method sends nothing if the user has not consented or Adobe is unavailable ({{P:apps/shared/src/containers/AdobeExperiencePlatform.ts:113}}) and, if all is well, uses MobileCore.trackState ({{P:apps/shared/src/containers/AdobeExperiencePlatform.ts:107}}).
  3. Native: action (click). It goes through trackEvent ({{P:apps/shared/src/containers/Analytics.native.ts:510}}, {{P:apps/shared/src/containers/AdobeExperiencePlatform.ts:120}}), which uses MobileCore.trackAction. On TV, if the Edge flag is on, both are sent instead as an Edge event of type analytics.track ({{P:apps/shared/src/containers/AdobeExperiencePlatform.ts:83}}, {{P:apps/shared/src/containers/AdobeExperiencePlatform.ts:92}}).
  4. Web: page view. Analytics.web gathers the data and calls _satellite.track("virtual_pv", data) ({{P:apps/shared/src/containers/Analytics.web.ts:413}}). Actions use _satellite.track with the action name ({{P:apps/shared/src/containers/Analytics.web.ts:479}}). On web, AdobeExperiencePlatform.trackView is empty ({{P:apps/shared/src/containers/AdobeExperiencePlatform.web.ts:10}}): Analytics.web does it directly.
  5. A warning from the code. The code comments say a new property does not show up in Adobe until the Analytics team maps it to a variable in Adobe Launch, even if it reaches _satellite.track.

Eventos Edge y segmentos

Edge events and segments

  1. Nativo. sendExperienceEvent manda eventos a la red Edge de Adobe con Edge.sendEvent ({{P:apps/shared/src/containers/AdobeExperiencePlatform.ts:368}}, {{P:apps/shared/src/containers/AdobeExperiencePlatform.ts:395}}) y procesa la respuesta, por ejemplo los segmentos de audiencia.
  2. Web. El mismo método usa alloy, el SDK web de Adobe que carga Launch ({{P:apps/shared/src/containers/AdobeExperiencePlatform.web.ts:60}}, {{P:apps/shared/src/containers/AdobeExperiencePlatform.web.ts:77}}). Si alloy no aparece en 5 segundos (por ejemplo, con un bloqueador), el evento se omite sin error ({{P:apps/shared/src/utils/alloy.ts:61}}). Un monitor de alloy lee los segmentos de cada respuesta ({{C:src/utils/loadSDKs.web.ts:107}}, {{C:src/utils/loadSDKs.web.ts:147}}).
  3. Video. La analítica de reproducción es aparte: useCTVAnalytics ({{C:src/components/CTVVideo/useCTVAnalytics.tsx:17}}) arma la configuración que el reproductor usa con los conectores de Adobe (incluido Adobe Edge, {{C:src/components/CTVVideo/CTVVideo.tsx:227}}).
  1. Native. sendExperienceEvent sends events to Adobe's Edge network with Edge.sendEvent ({{P:apps/shared/src/containers/AdobeExperiencePlatform.ts:368}}, {{P:apps/shared/src/containers/AdobeExperiencePlatform.ts:395}}) and processes the response, for example audience segments.
  2. Web. The same method uses alloy, Adobe's web SDK that Launch loads ({{P:apps/shared/src/containers/AdobeExperiencePlatform.web.ts:60}}, {{P:apps/shared/src/containers/AdobeExperiencePlatform.web.ts:77}}). If alloy does not appear within 5 seconds (for example, with a blocker), the event is skipped without an error ({{P:apps/shared/src/utils/alloy.ts:61}}). An alloy monitor reads the segments from each response ({{C:src/utils/loadSDKs.web.ts:107}}, {{C:src/utils/loadSDKs.web.ts:147}}).
  3. Video. Playback analytics are separate: useCTVAnalytics ({{C:src/components/CTVVideo/useCTVAnalytics.tsx:17}}) builds the configuration the player uses with Adobe's connectors (including Adobe Edge, {{C:src/components/CTVVideo/CTVVideo.tsx:227}}).
