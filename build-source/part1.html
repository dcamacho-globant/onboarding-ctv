CTV Web — ConnectedCTV Web — Connected

Connected es una sola app de React Native que se convierte en la app de la NFL para pantallas de TV (tvOS, Fire TV, Android TV) y, con una versión web, para TVs con navegador (Samsung, LG, Xbox, Vizio): pide datos a la API de la NFL, los guarda en estado y los muestra en pantallas que se manejan con el control remoto.

Connected is a single React Native app that becomes the NFL app for TV screens (tvOS, Fire TV, Android TV) and, through a web build, for browser-based TVs (Samsung, LG, Xbox, Vizio): it requests data from the NFL API, keeps it in state, and shows it in screens driven by the remote control.
